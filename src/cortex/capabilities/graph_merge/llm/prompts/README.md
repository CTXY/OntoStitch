# Graph Merge prompts

The production two-stage integration uses `integration_identity.md`, `integration_consolidate.md`, `integration_node_assess.md` and `integration_reconcile.md` through `llm/integration.py`. Each phase receives one Markdown role prompt and serialized task context. Type and operation guidance is available on demand through read_guidance rather than repeated in every system prompt. Writer output uses buffered mutation tools plus StageCompletion; assessment returns IntegrationReview. Exact Pydantic tool schemas are generated by code, not copied into prompts. Local per-call traces record the actual system prompt hash, inputs, tool schema names and usage.

The legacy group workflow uses `PROMPTS` in `__init__.py`: `load_prompt` composes a role file, shared.md and a merge_types contract; its identity role uses its own file. These legacy/ablation roles remain separate from the production two-stage orchestration. Prompts stay versioned with code; there is no runtime download of latest prompts.

Use clear sections for role, evidence/scope, checks, edits/recovery and finish. A small example is useful only when it resolves a recurring ambiguity. Keep type requirements in the shared asset contract and retrieve them when needed. Dynamic task evidence must not be treated as instructions. The legacy workflow wraps that context in a merge_context block; integration uses a structured JSON user message.

When changing prompts, run the group-workflow tests and the N1/N2/N3 integration examples. A prompt change invalidates resuming a run made with a different prompt version. Record the hash, not the full source SQL, in remote trace metadata.

## Formatting

Write each prose paragraph and each list item on one physical line; use editor soft wrapping for display. Keep blank lines between sections and paragraphs. Preserve structural newlines and indentation in headings, nested lists, fenced examples, JSON/SQL and output envelopes. Apply the same convention to shared contracts, YAML prompt blocks and model-visible tool descriptions.
