# same_role_neighbors: multiple neighbors in the same role

## Trigger, cause, and normal state
A Concept/Event connected to multiple targets via the same predicate may confuse roles or lose combination knowledge, or it may be normal independent multi-value.

## General example (illustrative, not this round's graph records or evidence)
City served_by multiple airports can be kept; a Route with clearly sourced first A then B must retain the order.

## Necessary local material
All nominated owner's relationships for the specified predicate and direction, endpoint meanings, and any corresponding Concept metadata group. Completeness concerns this role, not every role of the owner.

## Writer judgment and modification
Verify the complete relationship of the same predicate and endpoint meanings; when evidenced, clarify specific roles and add missing objects. In a Concept, retain evidenced pairing/order metadata; do not guess constraints from array order, do not merge unconfirmed neighbors, and do not write Concept metadata for an Event.

## Assessment check points
Check each independent fact and original group-level proposition; do not reject merely because there is no parent node or optional metadata, and do not ignore pairing knowledge merely because the edge still exists.
