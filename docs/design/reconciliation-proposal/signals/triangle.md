# triangle：直接边与两段路径

## 触发与理想状态
- **触发条件**：`A→B→C` 与 `A→C` 同时存在即触发，不限定谓词，也未检查范围/分支或推导规则。
- **健康与例外状态**：直接边可能是独立事实、必需计算输入或合法显式层级；结构不证明冗余，不要求消除三角形。

## 核查材料与示例
- **推导前提**：掌握 A/B/C 指代、三个端点对的完整相关边、谓词契约、条件与分支。拟以路径替代直接边时，须有明确推导规则和消费者契约。
- **直接表示与来源**：涉及 Metric 时读完整 expression/refs 与全部直接输入；拟退役边时补来源、引用 metadata 与后继。
- **必须保留示例**：M 的公式引用 X、Y，虽然 X 也依赖 Y，M→Y 仍是直接输入。
- **不可推导示例**：Employee works_for Company 与 Company located_in City 不推出 Employee lives_in City。
- **可选简化示例**：同范围、可共同成立的 is_a 传递路径可解释直接层级边，但仍需来源/消费者允许，不强求删除。

## Writer 判断与调整步骤
1. **核实推导许可**：明确待检命题及允许的推导；一般业务谓词不默认传递，is_a 也不自动传播任意业务关系。
2. **验证最终前提**：若删直接断言，须从**最终保留图**独立推出同范围命题，不能依赖已删边循环自证或跨互斥分支拼路径。
3. **保留直接表示**：保留必要直接输入/表示及组合知识；来源只证明原结论时，不广播成支持更强路径前提。
4. **表示与身份边界**：无法在现有契约中保留推导来源时保留直接边；身份问题交回 Identity，不从三角形合并节点。

## Assessment 核查要点
- **事实核验**：对每条被删断言验证最终推导前提、分支相容、直接表示需求及来源后继。
- **保义与通过边界**：合法三角形可不修改；没有推导许可的删边、间接路径替代直接输入或强行来源归因均为缺陷。
