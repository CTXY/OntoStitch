# parallel_assertions：同一端点对的多条断言

## 触发与理想状态
- **触发条件**：同一有序语义端点对有多条边即触发，**谓词不必相同**；可能重复或冲突，也可能是正常不同角色。
- **健康状态**：相同端点可保留多个具体谓词或不同有据条件；只有同一事实、相容范围的重复/互补说明才适合合并。

## 核查材料与示例
- **比较材料**：掌握两端指代、完整有向关系集合、各谓词契约、说明、条件/分支和来源；涉及分支时读决定含义的完整版本。
- **变更影响**：拟合并/退役时补齐旧记录、后继及引用这些边的 Concept metadata，不扩展无关邻域。
- **保留示例**：Conference 对同一 University 的 organized_by 与 sponsored_by 表示不同角色。
- **合并示例**：同范围两条等义 submitted_by 边可归并说明与来源。
- **错误示例**：sender/recipient 因对象相同就压成 participant；不同分支的边删掉范围后当公共事实。

## Writer 判断与调整步骤
1. **比较断言**：比较真实角色、谓词、方向、条件与分支，不只比较文字或端点。
2. **合并或保留**：同一事实可整合，角色/条件不同保留多条；确认错误才修正。合并同步旧边后继和引用，不以减边为目标。
3. **缺前提与身份边界**：差异若来自身份安排交回 Identity；尚缺相容性前提则明确记录，不能将未知强写为冲突。

## Assessment 核查要点
- **事实核验**：逐条追踪旧断言在真实候选中的保留方式、来源和范围，确认没有丢角色或广播分支。
- **保义与通过边界**：多条合法边可以通过；一条宽泛边也可能失真，边数不是验收标准。
