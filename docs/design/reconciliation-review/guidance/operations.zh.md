# operation_registry 中文对照

以下按实际返回顺序完整保留 intent ID，翻译其自然语言定义。它是可按需读取的 registry，不是必须逐项抽取或创建的 Rule 清单。

- **joinability**：选择连接已完整表达的含义所需的表路径或键关系。路径可以是直接路径，也可以使用一张路由表。
- **population_average_comparison**：将已完整表达的存储含义或 Metric 与同一请求总体上的平均值比较；平均计算与比较留在 Rule 中，不创建辅助 Metric。
- **count_aggregation**：返回请求实体或取值的数量。
- **existence_check**：返回是否至少存在一个满足条件的结果。
- **boolean_output_encoding**：使用输出标签返回请求的 yes/no 答案。
- **result_deduplication**：当 SQL 来源可能产生重复行时，每个请求输出项或输出元组只返回一次。
- **extreme_value_selection**：返回一个标量最小值或最大值，不返回承载该值的行。
- **top_k_selection**：返回与排在最前或最后 K 个取值对应的实体行。K 可以是一。它决定排名和行是否纳入，不决定输出哪些物理字段表示。允许透传请求属性；额外固定字段集合策略属于单独决策。对于竞赛排名，rank 等于严格排在前面的合格行数加一：统计严格更优行可以保留并列。将窗口函数的某个替代实现判断为错误前，检查是否使用相同的入选条件、分组与 NULL 排序。
- **rank_output**：为每个请求结果行返回序数排名或考虑并列的排名值。
- **column_binding_choice**：当证据表明存在超出静态 Concept 匹配、且会产生实质结果差别的选择时，决定哪些受支持字段、联合字段组或表示参与答案。它选择内容，不选择列顺序、格式或行/列输出形状。选择字段集合，不同时决定如何排列已选取的值；排列是独立决策。不要重复已经解决的术语到字段/值映射。
- **aggregation_grain**：在重复记录与连接中保留请求的计数或聚合单位；区分行、对象与事件粒度。
- **null_semantics**：保留筛选、聚合或算术中有证据支持的 NULL 含义，不得无依据地把缺失值当成已记录值。
- **temporal_alignment**：为请求的业务事件或时长选择有依据的发生时间、区间边界与时间对齐方式。
- **population_scope**：当证据区分了计算中所指的组或某一侧时，保留请求总体与固有 Metric 范围。
