# Ontology workbench examples

These are existing merge results from the supplied BIRD `results_final` archives,
converted to the current Cortex schema. They are **not** generated by the web
preview's uploaded pairs. See `provenance.json` for original hashes and the graph
envelopes' `compatibility.changes` for the preserved conversion audit.

Both snapshots pass `GraphManager.validate_state()` with the current root schema:

| Archive | Nodes | Edges | Conflict records |
| --- | ---: | ---: | ---: |
| financial | 245 | 339 | 4 |
| thrombosis_prediction | 284 | 381 | 4 |

Conversion preserves conflict candidates using compact overrides, canonicalizes
column/target IDs, converts physical equality joins to column_pairs, removes old
schema fields into the audit, and recompiles declared reference edges. One legacy
thrombosis metric references concepts: their unambiguous single targets are inlined
into the expression with physical reference placeholders. Ambiguous targets are
rejected rather than guessed. Original archives are never modified.

SQLite files are not committed. Register local BIRD databases using
`scripts/prepare_ontology_demo.py`; see `docs/design/ontology-web-implementation.md`.
